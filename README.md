# ⚡ SmartClass AI: Intelligent IoT Classroom & Operations Hub

A modern, hybrid AI & IoT dashboard built with **Streamlit**, **Python**, and **Machine Learning** to monitor and manage smart campus environments in real time.

## 🚀 Features
* **Live Environmental Monitoring:** Real-time tracking of temperature, humidity, occupancy, light levels, and energy usage.
* **Traditional ML Anomaly Detection:** Background telemetry checks using Scikit-learn to spot equipment malfunctions or sudden climate spikes.
* **Generative AI / Smart Controls:** Interactive hardware toggles and simulated autopilot mode for automated climate management.
* **Dark Mode UI:** Sleek, high-scannability interface inspired by modern IoT control centers.

## 🛠️ Tech Stack
* **Frontend & Backend:** Streamlit (Python)
* **Data Processing & ML:** Pandas, NumPy, Scikit-learn
* **Deployment:** Streamlit Community Cloud & GitHub
